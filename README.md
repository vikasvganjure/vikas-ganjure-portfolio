## ✨ Key Portfolio Features

- **Modern Architecture**: Fully converted from legacy static code to a type-safe **React 18 + TypeScript** application bundled with **Vite 6**.
- **Tailwind CSS Design System**: Fluid typography, responsive grids, and subtle glassmorphic backdrop filters (`backdrop-blur-md`).
- **🌓 Dual-Mode Theme Switcher**: Instant switching between **Deep Zinc Dark Mode** and **Clean Slate Light Mode**, persisted across user visits via `localStorage`.
- **Zero-Image Developer Aesthetics**: Personal and stock photos replaced with:
  - An interactive **Developer Terminal Card** with real-time tab switching between Java and JSON code configurations, and one-click code copying.
  - A 4-metric **Engineering Highlights Grid** (8.16 CGPA, 4+ Work Roles/Internships, 12+ Core Tech Stacks, Pune Base).
  - Clean SVG-backed academic credential badges.
- **Dynamic Typewriter & Micro-Interactions**: Real-time typewriter cycling through core roles, active scroll-spy navigation, and subtle card hover elevations.
- **Interactive Filtering**: Filter technical skills and featured projects by domain (Backend, Full Stack, Security / ML, Frontend).
- **Working EmailJS Contact Gateway**: Fully functional inquiry form connected to EmailJS with live form validation, submit states, and a one-click copy email button.
- **100% Responsive**: Tailored for mobile devices (320px+), tablets, desktops, and ultrawide displays with a smooth sliding mobile drawer menu.

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- [npm](https://www.npmjs.com/) (version 9.0 or higher)

### Installation & Run

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/vikasvganjure/vikas-ganjure-portfolio.git
   cd vikas-ganjure-portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your web browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
   The compiled static assets will be created in the `dist/` directory.
